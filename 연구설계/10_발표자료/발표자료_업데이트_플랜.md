#### 슬라이드 12 — 전체 프레임워크 흐름도
- **현재:** Step 1~4 (투자지표 → 가중치 → PI → 최적화)
- **변경:** Fig 3.1 기반으로 업데이트
  - 시작점: "CNAIM 기반 PoF·CoF·리스크"
  - 4단계 흐름: 입력 데이터 구성 → 투자효과 지표 산정 → 다기준 PI 산정 → 포트폴리오 최적화
  - 산출물: 투자가치 / 설비단위 PI / 통합 PI / 5개년 최적 포트폴리오

#### 슬라이드 13 — Step 1: 투자지표 산출
- **현재:** 리스크 저감량·SAIDI·투자가치/효율 소개
- **변경:** 투자가치 산식 추가. 6개 하위지표를 3축으로 명시

| 평가축 | 하위지표 |
|---|---|
| 경제성 | 투자가치, 투자효율 |
| 신뢰도 | SAIDI 저감, 고장예측대수 저감 |
| 안전·환경 | 안전 영향 저감, 환경 영향 저감 |

#### 슬라이드 14 — Step 2: 가중치 산정
- **현재:** "Fuzzy-AHP" 단독 설명
- **변경:** 전면 개편. AHP → Fuzzy 보정 → BWM 비교의 3단계 구조

| 방법 | 역할 |
|---|---|
| AHP | 전문가 쌍대비교 → 기준별 상대가중치 산정 |
| Fuzzy 보정 | 언어적 모호성 정량화 → 가중치 안정성 확인 |
| BWM | AHP·Fuzzy 결과의 해석력 검토용 보조 비교 |

- 가중치 결과 수치 포함: **경제성 35.41% / 신뢰도 26.17% / 안전·환경 38.42%**

#### 슬라이드 15 — Step 3: PI 산정
- **현재:** 단일 PI 산정 수식
- **변경:** 2단계 PI 구조로 업데이트
  - **설비 단위 PI:** 6개 하위지표 × AHP/Fuzzy 보정 가중치 → 동일 설비유형 내 우선순위
  - **통합 PI:** 설비단위 PI × 설비유형 가중치(전문가) + 비용보정 가중치 → 이종 설비 전체 통합 비교
  - α=0.5 기준 혼합가중치 주요 수치: 주상변압기 30.46% / 가공배전선로 21.94% / 가공개폐기 16.33%

#### 슬라이드 16 — Step 4: 포트폴리오 최적화
- **현재:** "유전알고리즘 적용" 중심 설명
- **변경:** 전면 개편. ILP 중심, 5가지 비교 방식 표

| 방법 | 성격 | 역할 |
|---|---|---|
| 리스크 Greedy | 리스크 순위 기반 정렬 | 기준선 |
| IV ILP | 투자가치 목적함수 ILP | 경제성 최적화 기준해 |
| PI ILP | 설비단위 PI 목적함수 ILP | 다기준 설비 단위 최적화 |
| 후보제한형 ILP | PI 후보군 → 통합 PI ILP | 보조 비교 |
| **통합형 ILP** | 전체 후보군 → 통합 PI ILP | **대표 방식** |

### ⑤ 결론 (슬라이드 26~28)

#### 슬라이드 26 — 결론 및 기여
- **현재:** 구버전 결론 (리스크·성능·경제성 기반 Fuzzy-AHP 중심)
- **변경:** 학술적·실무적 기여 재정리

**학술적 기여 4축:**
1. 리스크 → 투자가치 → PI → 포트폴리오의 통합 투자계획 절차 제시
2. AHP + Fuzzy 보정의 전문가 참여형 가중치 구조 (Human-in-the-loop)
3. 설비단위 PI → 통합 PI로 이종 설비 간 통합 비교 체계 구축
4. 246회 민감도·강건성 분석을 통한 방법론 검증
