### 1.3 계보에서 나오는 쟁점
1. **한전 R22TA31·R20TA08 보고서의 표지에는 "대외 발표·활용·인용·복사 시 전력연구원 사전승인" 문구가 있다.** 논문 제2장의 AIP 배경, 투자가치 용어 정의("Value" 혼란 방지를 위해 "투자가치"로 통일), 투자가치 모델링 서술은 이 보고서의 구조·논리와 가깝다. 12자 단위 문자열 겹침을 측정한 결과 장별 원고에서 15% 이상 겹친 문단은 제2장 89개 중 3개(최대 24%)이고 나머지 장은 없었다 [검증]. 문장 복제는 적으나 **개념·구성의 계보가 본문과 참고문헌에 드러나지 않는다.** 논문 공개·SCI 투고 전에 (a) 승인 여부, (b) 인용 방식, (c) 기여 주장 범위를 정리해야 한다.
2. 투자가치는 "제안 지표"가 아니라 기존 방법의 적용이다. 기여는 PI·통합 PI·정책 제약 분석·견고성에 둔다.
3. Fuzzy 보정은 이식된 방법이므로 정당화(또는 대체)가 필요하다.

## 2. CNAIM 구현의 실제 (코드 `cnaim_clean_pipeline.py` + 데이터 [검증])

### 2.1 데이터 생성 방식
- 설비 6종 21,893기. 연령은 1~최대연령 균등분포, 상태 중증도 `0.7×연령비 + N(0, 0.18)`를 모든 관측·측정 항목에 동시에 적용(고정 seed 42, 단일 표본).
- PoF: CNAIM 3차 곡선(`K·[1 + C·H + (C·H)²/2 + (C·H)³/6]`, C=1.087, H_NEW=0.5, H_EOL=5.5, 현재 HS 상한 10, **미래 HS 상한 15**).
- CoF: CNAIM v2.1 Table 16 기준값(재무·안전·환경·네트워크)에 설비별 보정계수를 곱해 합산. 교체비용 = 재무 CoF × 도급비율(1.1~1.5).
- 투자가치 반사실(counterfactual): 교체하지 않는 경우 설계수명 전 기간(60/55/55/55/55/100년)의 PoF×CoF를 할인 합산하고, 교체하면 신품 곡선을 합산해 그 차이를 리스크 저감량으로 둠.

## 3. 참고 패키지(한국교통대 사외공모 최종평가 자료) 재해석

**성격**: 한전 기초연구 사외공모 과제의 최종평가 자료다. 평가표는 목표달성도(20), 연구수행노력도(15), 개발성과(35), 결과활용성(30) 구조로 읽힌다(PDF 인코딩 깨짐으로 배점은 숫자 배열에서 판독, 세부 문구 일부 미확인). **과제 평가 기준이며 학위·저널 심사 기준과 다르다.**

**차용할 원칙**
1. 근거 출처 기호(K 한전 데이터 / K-D 집계 인용 / M 모의 / A 잠정 / U 미확인)를 모든 수치에 부여. 본 논문에는 한전 데이터가 없으므로 "CNAIM 원값 / 공개자료 인용 / 연구자 가정 / 미확인" 4분류로 응용 가능. 합성 데이터 약점을 구조적으로 정직하게 드러내는 장치.
2. 대표 자산 1대를 입력부터 판정까지 끝까지 추적하는 계산 사례(본문에 추가).
3. 비보상 안전 게이트: PI 가중합의 보상성(치명 지표 희석)을 "하드 제약 + PI"로 보완. 한전 R22TA31도 Scoring 방식의 이 약점을 지적한 바 있음(이 보고서 서술 [검증]).
4. 모의자료로 임계값을 역산하지 않는 원칙: 후보 30%, P95 정규화, α=0.5 같은 설계값의 근거를 명시.
5. 현장 절차·환류 루프 서술(방법론의 일부).

**따르지 않을 부분**: 해당 과제는 설계 단계로 가중치·임계값이 실증 전이고 비용값이 모의값이다. 학위·SCI 정량 기여의 모델로는 부족하다. 한전 내부 자료는 논문에 인용하지 않는다.

## 6. 추천: "CNAIM 기반 계통 인지형 이종 설비 투자 포트폴리오: 현지화 불확실성 하의 견고성"

### 6.1 구성(세 축)
**A. 기반 정비(옵션 1)**
1. 반사실 재정의: 현행(설계수명 누적, 갱신 없음)과 대안(계획기간 + 잔존가치, 고장 시 교체를 반영한 갱신 과정, CNAIM Long-term Risk 가중표 기반)을 병행 산정하고 포트폴리오 차이를 보고.
2. 통화·단가·카테고리 매핑 정정 또는 명시. 평균단가는 현 데이터 기준 재산정(기존 값과 병행 보고).
3. 지표 중복 정리: PI 하위지표 간 상관·제거 실험, 안전 게이트 도입 검토.
4. Fuzzy 보정의 정당화 또는 "가중치 불확실성 전파(Dirichlet·Monte Carlo)"로 대체.
5. 분해 실험(배분구조 × 목적함수, 유형 가중치 4종), 독립 seed 10~20개.
6. 출처 4분류 표기, 대표 자산 1대 추적 사례.

**B. 현지화 불확실성 분석(옵션 2의 재정의)**
- 불확실 파라미터: K(유형별), 정상 기대수명, 위치·운전 계수, 미래 HS 상한, 기준 CoF(통화·스케일), 연결고객수·정전시간, 교체비용·도급비율, 할인율.
- 방법: 파라미터 범위를 공개 참조값(CNAIM 원값, 해외 사례) 기준으로 설정 → 전역 민감도(Sobol 등)와 Monte Carlo → 각 표본에서 포트폴리오 재최적화 → **선택 설비 안정성, 후회(기준해를 쓴 경우의 손실), 파라미터별 기여도**.
- 산출: "어떤 파라미터를 먼저 현지 데이터로 확정해야 의사결정이 바뀌는가"의 순위(정보가치 관점). 로컬라이제이션 절차(데이터 등급 → 우선순위 → 갱신)를 방법론으로 제시.
- 신규성 판단: CNAIM 현지화 필요성은 알려져 있으나(§4) 결정 영향 정량화는 이번 검색에서 확인하지 못함. **신규성 주장은 문헌 검토 후 확정.**

**C. 계통 인지형 평가(옵션 3)**
- 22.9 kV 방사상 피더(공개 표준 피더 + 한전식 구성 가정)에 구간 개폐기·연계 개폐기·변압기·선로·케이블을 배치하고 고장 모드별(보호·분리·절체·수리) 영향 고객·정전시간을 계산.
- MATLAB 조류로 절체 시 전압·열 제약 확인.
- 가산 SAIDI 근사로 선택한 포트폴리오를 토폴로지 평가기로 재평가해 **근사 오차의 의사결정 손실** 정량화. 솔버는 가산 근사 ILP, 피더 분해, 평가기 내장 GA를 비교.
- 설비 데이터와 피더의 연결: 기존 자산의 `connected_customers`·`outage_duration_min`과 정합되게 피더를 생성(합성 위의 합성임을 명시).

### 6.2 논문 분할

### 6.3 발표 서사(교수 어필)

- 방어 준비 목록: 합성 데이터와 출처 분류, 통화·스케일, 반사실 정의, 지표 중복, 가중치 불확실성, α 근거, 후보군 30%, ILP vs GA(한전 보고서의 GA 채택 근거와의 차이), 결과 재현성.
