## 0. 결론

1. **신규성 판단이 바뀌었다.** 수집한 문헌에서 이 논문의 핵심 구조와 매우 가까운 선행연구가 확인됐다. 특히 *IEEE Trans. Power Delivery* 2026 "Large-Scale Multi-Period Optimal Asset Renewal Planning: A Comprehensive and Efficient MILP Approach"는 변압기·개폐기·케이블을 하나의 다기간 MILP로 통합하고 사후(reactive) 교체, 정비, 고장비용, 인력·신뢰도 제약을 함께 다룬다(초록 확인). 따라서 "이종 설비의 다년 포트폴리오 ILP"는 기여로 주장할 수 없다. 기여는 **PI·통합 PI의 분해 검증, 현지화 불확실성, 계통 인지 평가** 쪽에 있어야 한다.
2. **추천 구성은 유지하되 순서와 범위를 조정한다.** 한 달 안에는 (A) 모형·데이터 재산출과 분해 실험, (C) 계통 인지 평가의 개념 증명(PoC) 한 장, (B) 불확실성 분석의 축소판까지 하고, SCI용 본 분석은 발표 이후로 둔다.
3. **새 참고자료(변전소 PRA 제안서)는 통합 PI를 개선하는 구체적 방법을 준다.** 설비유형 가중치(전문가+단가 혼합, α)를 **시스템 중요도(Fussell–Vesely, Birnbaum 등) 기반 가중치**로 바꾸면 가장 임의적인 부분이 물리적 의미를 갖는다. 다만 이 자료는 업체 영업 자료라 인용하지 않고 아이디어 출처로만 쓴다.
4. 이전 점검에서 지적한 반사실(재고장 미반영) 문제는 Han 등의 사후 교체 모형과 같은 방향이다. **갱신 과정을 반영한 재정의가 필수**다.

## 4. 변전소 PRA 제안서(`ATS Presentation KEPCO FINAL.pdf`) 분석

**성격**: 미국 컨설팅·소프트웨어 업체(ATS)가 한전에 보낸 영업·제안 자료(2026-09-02, 76쪽)다. 변전소 3개소 대상 무상 PoC를 제안한다. 효과 수치(비용 20% 절감, 수억 달러 절감 등)는 업체 주장이며 검증되지 않았다. **논문에 인용하지 않고 아이디어 출처로만 활용한다.**

| 자료의 주장·방법 | 이 논문에 주는 시사점 |
|---|---|
| 건전도 점수는 화폐화 리스크가 아니며 절대·상대 의미가 없다 | CNAIM은 건전도→PoF→화폐화 리스크로 이어지므로 해당 비판의 일부는 해소됨. 발표에서 "CNAIM이 건전도 점수와 다른 점"을 한 장으로 설명 가능 |
| 연령만의 Weibull은 예측력이 약하다(인용 사례 포함) | 이 논문의 합성 데이터는 상태를 연령에서 생성(중증도 = 0.7×연령비 + 잡음)하므로 연령-상태 분리 검증은 불가. 한계로 명시하고 생성 상관 계수에 대한 민감도 분석 필요 |
| 자산 PoF 순위와 시스템 중요도 순위가 다르다(예: 변압기 우선순위가 PRA 하에서 달라짐) | **설비 단위 순위만으로는 시스템 우선순위가 보장되지 않는다.** 계통 인지 평가(C)의 직접적 동기 |
| 결함수(minimal cut set)와 Fussell–Vesely·RAW·RRI 중요도로 핵심 설비 도출 | **통합 PI의 설비유형 가중치를 중요도 기반으로 재정의**하는 방법적 근거. 단가 역수 같은 임의 가중을 대체 |
| 핵심 설비 10개의 교체 조합 2^10을 모두 평가해 효율적 경계(비용–P(f), ROI) 도출 | 소규모 피더·변전소 PoC에서 완전열거 가능. 제안 ILP 해와 비교하는 검증 기준으로 활용 |
| 리스크 분포(P50/P90/P95), TVaR, 보험 의사결정 | 현지화 불확실성 분석의 출력 형식(분포·분위수)으로 활용 |
| 런투페일(run-to-failure) 시나리오로 "절대 고장 나면 안 되는 설비" 식별 | 사후 교체(기준선)를 대안으로 병기하는 설계와 일치 |
| 완전 재건축($20~40M) vs 핵심 10개 교체($2.4M)의 한계수익 체감 | 예산 민감도 해석(1.3배 이상에서 수렴)과 연결 가능 |

**해석상 주의**: 업체 자료의 상태·고장 데이터는 업체 보유 데이터를 쓴 것이며, 이 논문은 공개·합성 데이터만 사용하므로 그 데이터 기반 주장은 재현할 수 없다.

| 반사실(미교체 시 재고장 미반영) | Han(사후 교체 모형), Hamad(MDP), Bjerkebæk(강제 교체) 모두 갱신 과정을 반영. **현행 방식은 재정의 필요** |
| 통합 PI(전문가+단가 혼합 가중) | 임의성이 크고 단가 값이 stale. 중요도 기반 재정의 후보 |
| AHP + Fuzzy 보정 | AHP 우선순위는 선행 다수. Fuzzy 보정(Wr×Wa)은 출처가 비전력 분야 논문이며 정당화 필요 |
| SAIDI 가산 모형 | 계통 인지 평가의 부재가 약점. Bjerkebæk 등이 계통 신뢰도 평가와 결합 |
| 합성 데이터 | 한계 인정. 출처 분류, 공개 벤치마크화, 복수 표본으로 방어 |
| 의사결정 손실·현지화 영향 | 문헌상 빈 자리. 차별 기회 |

### 6.2 분석 설계 (발표 전·후)
1. **분해 실험**: 배분구조(유형별 고정/공동예산) × 목적(리스크/투자가치/설비 단위 PI/통합 PI). 같은 후보·같은 총예산.
2. **통합 PI 재정의**: 설비유형 가중치 = 전문가 선호(정책) 와 시스템 중요도(물리)의 분리. 중요도는 대표 피더·변전소 모형에서 산정(아래 6.3).
3. **계통 인지 평가(PoC)**: 표준 시험계통(예: IEEE RBTS 배전 모형, 서지는 확인 필요)에 6개 설비 유형을 배치하고, 가산 SAIDI와 토폴로지 평가기 결과를 비교. FV·Birnbaum 산정, 소규모 완전열거로 효율적 경계 도출.
4. **현지화 불확실성 분석**: K, 설계수명, 위치·운전 계수, 미래 HS 상한, 기준 CoF, 고객·정전시간, 비용·도급비율, 할인율을 범위로 두고 전역 민감도 + 몬테카를로 재최적화 → 선택 안정성, 후회, 파라미터 기여도. 출력은 분위수(P50/P90/P95).

### 6.3 계통 인지 모형 스케치
- 설비 → 피더 구성요소 매핑: 구간 개폐기(sectionalizer), 연계 개폐기, 변압기(부하점), 가공선로·지중케이블 구간.
- 고장 모드별 영향: 보호 동작 → 구간 분리 → 절체 가능 여부 → 수리. 영향 고객·정전시간 계산(해석적 FMEA 또는 몬테카를로).
- 중요도: 결함수(minimal cut set) 기반 FV, Birnbaum, RAW/RRW. 가산 모형은 이 중 "단일 설비 영향의 합"에 해당하는 특수한 경우로 해석.
- MATLAB 조류: 절체 시 전압·열 제약 확인(2차 단계).

## 9. 발표 전략(교수 어필)

- 한 줄: "공개 방법론 CNAIM으로 구성한 이종 설비 투자 포트폴리오가 현지화 파라미터와 계통 구조에 얼마나 민감한지, 무엇을 먼저 확정해야 하는지를 보인 연구."
- 자산관리: 반사실·갱신 과정, 출처 체계, 현지화 순위. 전력계통: 토폴로지 평가와 중요도 도입 그림 한 장(같은 설비 교체도 위치에 따라 효과가 다름).
- 방어: 합성 데이터, 반사실 정의, 지표 중복, 가중치 불확실성, 통합 PI의 의미, ILP vs GA, 선행 연구 대비 위치(Han 2026 등).

## 10. 결정이 필요한 사항
1. 반사실 재정의의 기본안(갱신 과정 + 평가 구간 H)과 기준선 병행 여부.
2. 통합 PI를 중요도 기반으로 바꾸는 것에 동의하는지(전문가 가중치는 정책 선호로 별도 유지).
3. 한 달 범위(6.1 + PoC 한 장 + 축소판)와 발표 이후 논문 우선순위(P2 중심 권장).
4. 계통 PoC에 쓸 시험계통(공개 표준 계통 선택)과 변전소 수준까지 확장할지 여부.
