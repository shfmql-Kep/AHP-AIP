# CNAIM CoF 분포 수정 및 MATLAB 재실행 안내

작성일: 2026-06-24

## 1. 수정 배경

기존 입력 데이터에서는 일부 설비의 CoF가 CNAIM의 설비유형별 영향도 구조와 충분히 맞지 않았다. 특히 지중케이블은 실제 배전계통에서 고장 시 굴착, 복구, 고객영향, 지중 접속부 영향 등이 크게 나타날 수 있는데, 기존 데이터에서는 CoF가 상대적으로 낮게 산정되어 투자가치와 포트폴리오 선택 결과가 왜곡될 가능성이 있었다.

이에 따라 입력 데이터 생성 파이프라인에서 CNAIM의 설비유형별 CoF 기준값과 영향요인을 반영하도록 수정하였다. 본 수정은 CNAIM 방법론 자체를 본 연구의 제안 방법론으로 사용하는 것이 아니라, 검증용 입력 데이터의 설비별 CoF 분포를 보다 타당하게 구성하기 위한 조정이다.

## 2. 반영 내용

### 2.1 설비유형별 CNAIM 참조 CoF 기준값 반영

대상 6개 설비유형은 CNAIM의 배전설비 범주 중 연구 대상과 가장 가까운 항목으로 매핑하였다.

| 연구 대상 설비 | CNAIM 참조 설비유형 |
|---|---|
| 주상변압기 | 20kV Transformer (GM) |
| 지상변압기 | 20kV Transformer (GM) |
| 가공개폐기 | 20kV Switch (GM) |
| 지중개폐기 | 20kV RMU |
| 가공배전선로 | 33kV OHL Conductor |
| 지중케이블 | 33kV UG Cable (Non Pressurised) |

### 2.2 CoF 영향요인 분포 반영

CoF는 더 이상 설비유형별 고정값으로만 적용하지 않고, 설비별 입지·환경·고객영향 조건에 따라 분포되도록 수정하였다.

| CoF 항목 | 반영 요인 |
|---|---|
| 재무 CoF | Type factor, Access factor에 대응하는 입지·접근성·선로길이·부식·침수 조건 |
| 안전 CoF | 설비유형 위험도와 설치 위치 위험도 조합 |
| 환경 CoF | 설비유형, 규모, 수계·해안·부식 환경 |
| 네트워크 CoF | 연결고객 수와 고객 민감도 |

이에 따라 `input_assets.xlsx`에는 다음 보정계수 컬럼이 추가되었다.

- `cof_financial_factor`
- `cof_safety_factor`
- `cof_environment_factor`
- `cof_network_factor`

`pof_5yr_output.xlsx`에는 다음 CoF 결과 컬럼이 포함된다.

- `cof_financial_kkrw`
- `cof_safety_kkrw`
- `cof_environment_kkrw`
- `cof_network_kkrw`
- `cof_total_kkrw`

기존 `cof_environment_adjusted_kkrw` 컬럼은 사용하지 않는다. 환경 기대영향은 `pof_YYYY × cof_environment_kkrw`로 산정한다.

## 4. CoF 수정 후 확인된 경향

CoF 분포 조정 후 지중케이블의 평균 CoF는 기존보다 높아졌다. 이는 33kV 지중케이블의 재무 영향과 네트워크 영향을 반영한 결과이다. 다만 지중케이블의 투자가치는 여전히 낮게 나타날 수 있다. 그 이유는 CoF가 증가하면 Risk 저감량도 증가하지만, 본 연구에서는 재무 CoF를 교체비용 산정의 기준값으로 함께 사용하므로 교체비용도 동시에 증가하기 때문이다.

따라서 지중케이블이 계속 선택되지 않는 경우, 이는 CoF 과소평가만의 문제가 아닐 수 있다. 추가 검토가 필요한 지점은 다음과 같다.

1. 지중케이블의 PoF 산정에서 선로 길이, 접속부, 설치환경이 충분히 반영되었는지
2. 교체비용을 재무 CoF와 동일한 기준으로 적용하는 것이 과도하게 보수적인지
3. 지중케이블의 SAIDI 및 네트워크 영향이 실제 배전계통 특성을 충분히 반영하는지
4. 케이블 교체 단위를 “개별 설비 1기”로 볼 것인지 “구간 단위”로 볼 것인지

## 5. MATLAB 코드 반영 내용

다음 MATLAB 파일은 연구설계 폴더 기준으로 입력·출력 경로를 재정렬하였다.

| 파일 | 반영 내용 |
|---|---|
| `연구설계/04_알고리즘/matlab/local_pi_matlab.m` | 입력 경로를 `02_입력데이터`, 설문 경로를 `03_설문조사`, 출력 경로를 `05_PI_산출결과`로 변경 |
| `연구설계/04_알고리즘/matlab/bwm_pi_matlab.m` | 위와 동일 |
| `연구설계/04_알고리즘/matlab/simulation_chapter_v2_matlab.m` | PoF 입력은 `02_입력데이터`, PI 입력은 `05_PI_산출결과`, 시뮬레이션 결과는 `06_시뮬레이션결과/본문_시뮬레이션`으로 변경 |
| `연구설계/04_알고리즘/matlab/sensitivity_analysis_fast.m` | 입력·PI·민감도 결과 경로를 연구설계 폴더 구조에 맞게 변경 |
| `연구설계/04_알고리즘/matlab/sensitivity_analysis_matlab.m` | 위와 동일 |

또한 `local_pi_matlab.m`과 `bwm_pi_matlab.m`에서 환경 기대영향 산정 컬럼을 다음과 같이 수정하였다.

```text
기존: pof_YYYY × cof_environment_adjusted_kkrw
수정: pof_YYYY × cof_environment_kkrw
```

## 6. 연구 결과 재산출을 위한 MATLAB 재실행 순서

새 CoF 분포가 `pof_5yr_output.xlsx`에 반영되었으므로, 기존 PI와 최적화 결과는 모두 재산출해야 한다. 권장 재실행 순서는 다음과 같다.

### 6.1 설비 단위 PI 재산출

```matlab
run("연구설계/04_알고리즘/matlab/local_pi_matlab.m")
```

출력:

```text
연구설계/05_PI_산출결과/local_pi_matlab.xlsx
```

### 6.2 BWM 비교 결과 재산출

BWM 비교군을 본문 또는 부록에서 계속 사용할 경우 실행한다.

```matlab
run("연구설계/04_알고리즘/matlab/bwm_pi_matlab.m")
```

출력:

```text
연구설계/05_PI_산출결과/bwm_pi_matlab.xlsx
```

### 6.3 통합 PI 재산출

설비 단위 PI가 바뀌었으므로 통합 PI도 다시 산정해야 한다. 통합 PI 산정 보조 스크립트는 Python 기반이다.

```powershell
.\연구설계\04_알고리즘\python\run_python_utf8.ps1 .\연구설계\04_알고리즘\python\integrated_pi_matlab.py
```

출력:

```text
연구설계/05_PI_산출결과/integrated_pi_matlab.xlsx
```

### 6.4 본문 최적화 시뮬레이션 재실행

본문 제4장 결과를 다시 뽑기 위해 실행한다.

## 7. 실행 전 주의사항

1. Excel 파일이 열려 있으면 MATLAB의 `writetable` 단계에서 쓰기 오류가 발생할 수 있으므로 관련 파일을 모두 닫는다.
2. 새 입력 데이터가 반영되었으므로 기존 `local_pi_matlab.xlsx`, `integrated_pi_matlab.xlsx`, 기존 시뮬레이션 결과는 이전 버전 결과로 취급한다.
3. MATLAB 실행 시 루트 `code` 폴더가 아니라 `연구설계/04_알고리즘/matlab` 폴더의 파일을 기준으로 실행하는 것을 권장한다.
4. 루트 `data` 폴더의 엑셀 3개도 동일한 최신 파일로 동기화되어 있으나, 논문 재현성 관리는 `연구설계` 폴더 기준으로 수행한다.
